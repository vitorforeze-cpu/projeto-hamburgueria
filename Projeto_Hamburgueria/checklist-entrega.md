# Checklist de Entrega

Conferir tudo antes de mandar o site para o cliente.

## Funcionamento
- [ ] Abre certo no celular (testar de verdade, não só no modo responsivo do navegador)
- [ ] Menu hambúrguer abre e fecha
- [ ] Todos os links do menu levam para a seção certa
- [ ] Botão de WhatsApp abre a conversa com a mensagem já escrita
- [ ] Mapa carrega
- [ ] Nenhum link com `href="#"` sem função

## Conteúdo
- [ ] Nome, endereço, telefone e horário conferidos com o cliente
- [ ] Preços atualizados
- [ ] Nenhum texto placeholder sobrando
- [ ] Sem erro de português (ler em voz alta)
- [ ] Toda imagem tem `alt`

## Técnico
- [ ] `<title>` e `<meta description>` preenchidos com nome + cidade
- [ ] Imagens comprimidas (site abrindo em menos de 3 segundos no 4G)
- [ ] Favicon no lugar
- [ ] CSS mobile first, com media queries só para telas maiores
- [ ] Código comentado e identado

## Entrega
- [ ] Publicado (Netlify, Vercel ou GitHub Pages)
- [ ] Domínio apontado, se o cliente comprou
- [ ] Explicado ao cliente como pedir alteração e o que está incluído
- [ ] Print do site salvo para o portfólio
